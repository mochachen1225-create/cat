# 陪我一生的貓

在網頁上養一隻貓，從下雨天在紙箱裡撿到牠開始，陪牠從小貓長到老貓，直到牠跟你說「謝謝你陪我一生」。

- 打開 `index.html` 就能玩（不需要安裝任何東西），進度會存在瀏覽器裡
- 撿到的貓花色隨機（11 種：橘貓、三花、賓士、暹羅、玳瑁⋯⋯），也可以上傳自家貓咪的照片
- 點貓可以摸摸（摸肚子小心被咬）；每天早上／下午／晚上可以餵食、玩逗貓棒、梳毛、清貓砂、看醫生
- 隨機事件：出國要不要帶／請誰照顧、家裡有老鼠、半夜踩奶、凌晨鬼叫、推杯子、送你蟑螂⋯⋯
- 選擇會有後果：有些當下就看得到數值變化，有些幾天後才發生（沒打預防針→貓瘟、沒結紮→噴尿、拖著不看醫生→急診）
- 照顧不好會發生真實的事：貓砂太髒會尿在床上、咬你拖去貓砂盆；一直不餵會翻垃圾桶、倒地送急診；零食太多會變胖。壽命會因此變短
- 可以快轉：按一次就一直快轉，遇到事件會暫停、處理完自動繼續；生病或健康變差時才會停下來
- 貓會在房間裡走來走去；摸摸會喵喵叫、呼嚕，摸太多會哈氣（聲音可以關掉）
- 結局有一封貓寫給你的信，和整個一生的回憶相簿
